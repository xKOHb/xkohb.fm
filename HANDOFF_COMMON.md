# ОБЩИЙ промпт: семейство проектов KOHbツ.FM / M1Z.FM / HMSTR.FM

Вставь этот файл + отдельный промпт нужного проекта (HANDOFF_PROJECT_*.md). Приложи `index.html`, `overlay.html`, `sfx.js`, `og.png` проекта.

---

Ты помогаешь развивать три одинаковых по коду сайта для радио-стримов на Twitch. Отвечай по-русски, коротко и по делу. Зрители присылают в чат ссылку (YouTube, Spotify и др.) или название трека, ведущий слушает, ставит оценку 1–10 и иногда добавляет трек в плейлист. Пишем «ведущий / ведущего» (у HMSTR «ведущая»).

## Главное правило
Три проекта держим **идентичными по коду**. Эталон: KOHbツ. Любую правку делаем там и переносим на M1Z и HMSTR (удобно писать Python-патч с `str.replace` и проверкой, что строка найдена ровно один раз, и применять его ко всем трём файлам). Отличаются только: название, ключи `<slug>_*`, комната `<slug>fm-`, канал по умолчанию, домен, баннер `og.png` (и род у HMSTR). Данные проекта лежат в его отдельном промпте.

## Файлы и хостинг
Чистый HTML/CSS/JS, без сборки и сервера. GitHub → Vercel. В корне: `index.html` (панель), `overlay.html` (оверлей для OBS), `sfx.js` (звуки, ключ из `window.SFX_KEY`), `og.png` (1200×630, версия `?v=N` в og-тегах).

## Что умеет панель
- **Очередь:** заявки вручную и из чата Twitch, drag-and-drop, дедупликация, лимит длины трека, приоритет донатов (`$`, слово-метка `cfg.donWord`). Кнопки VIP нет.
- **Плеер:** YouTube IFrame API, Spotify/SoundCloud через iframe, остальное виниловая заглушка и «↗ Открыть». Громкость только у YouTube.
- **Оценка** 1–10, теги, быстрые комментарии, «В плейлист», «Пропустить», «Следующий». Звуки: джингл, аплодисменты (9), горн (10), фейл (1).
- **Чат Twitch:** анонимный IRC, только чтение. Команды `!заказ, !sr, !order`, лимиты, чёрный список, «На проверке», голосование `!1…!10`.
- **Эфир:** ON AIR, слепой режим, ☕ перерыв (K), ⏳ «скоро начнём» (L), 🏁 конец стрима (E), компактный режим, «Лёгкий режим», статистика.
- **Итоги:** хит-парад, архив 60 эфиров, лучшее за 30 дней, сторис-PNG 1080×1920, экспорт плейлиста.
- **30 тем** (id в `data-theme`), светлая/тёмная, свой цвет `cfg.accent`. Цвета тем заданы в трёх местах: CSS панели, `STORY_PAL`, `[data-theme]` в `overlay.html`.
- **Показ вкладки** в оверлее (V), **настройки** в 9 раскрывающихся разделах.
- **Данные** в `localStorage` (`<slug>_fm_v1`, `_cfg`, `_theme`, `_vol`, `_arch`, `_brk`, `_photo`, `_coj`). Экспорт/импорт JSON `{S,cfg,arch}`. В экспорт и импорт **не входят** `ytKey`, `room`, `coKey`, `coOpen`.

## Оверлей (`overlay.html`)
Данные от панели по WebRTC (PeerJS, `?room=КОД`, пир `<slug>fm-<room>`), запасной путь через `localStorage`. Параметры: `bg=green`, `q=0`, `logo=0`, `scene=0`, `lite=1`, `sw=`, `chat=0|own`, `chaturl=`, `chan=`. Сцены «Перерыв», «Скоро начнём», «Конец стрима» (анимированный фон, винил **без смайлика**, кольцо-таймер). В сценах текста минимум: подсказка вида «Заказ трека: !заказ название», чипы «Средняя / Треков», до 3 карточек «Дальше в эфире». «Конец стрима» (v19): крупный заголовок, три карточки (Треков / Средняя / В плейлист), пьедестал топ-3, места 4–5 списком (`#sce`, `#sest`, `#seh`, `#sepod`).

## 🤝 Коллаб (БЕТА)
Без сервера, WebRTC (PeerJS), работает между любыми проектами. В интерфейсе везде помечен «БЕТА».
- Хозяин открывает комнату (`cfg.coOpen`), отдаёт код `<peer-id>~<coKey>`. Один гость. Гость видит очередь и трек хозяина, свой `S` не трогается (`save()` не пишет).
- Синхронизация: очередь, текущий трек, позиция/пауза, оценки обоих, заявки и голоса чата гостя, экран партнёра (`getDisplayMedia`, окно `#covid`).
- **Управление гостем** (`cfg.coCtl`, галочка у хозяина): next, skip, play/pause, go, del, don. Хозяин шлёт гостю `ctl` в каждом пакете состояния, гость без разрешения видит подсказку и команды не отправляет. Пауза/старт у хозяина идёт напрямую через плеер.
- **Переживает обновление страницы:** хозяин (комната остаётся открытой), гость (код хранится в `<slug>_coj`, автоподключение при старте peer и до 8 повторов раз в 4 с после обрыва). Выход вручную, «Отмена» или закрытие комнаты хозяином стирают сохранённый код. Плашка `#cobar` видна и хозяину (даже без друга), и гостю, и во время подключения.
- Гость при выходе сохраняет свои оценённые треки в историю и архив (`coSess`, `coFlush`).

## Код оверлея (важно)
`cfg.room` и `cfg.coKey` уникальны для каждого браузера и **никогда не переносятся** через экспорт/импорт (раньше из-за этого у двух людей совпадал код, и чужая панель управляла чужим оверлеем: `unavailable-id`). Если код всё же совпал: Настройки → OBS-оверлей → «🔄 Новый код оверлея» (создаёт новые `room` и `coKey`, нужно заново вставить ссылку в OBS).

## Горячие клавиши (не ломать)
N следующий · Пробел пауза · 1–9, 0 оценка (0 = 10) · P плейлист · S пропуск · O открыть · ↑/↓ громкость · M звук · B слепой · T тема · D светлая/тёмная · K перерыв · L «скоро начнём» · V показ вкладки · E конец стрима · C чат в оверлее.

## Формат данных
`S = {queue:[], pending:[], current:null, history:[], evId}`. Трек: `id,text,nick,comment,rating,note,pl,title,author,name,skipped,src,tags,votes,vn,vavg,t0,thumb,cover,noemb,don,co`. Архив: `{id,d,t:[{n,r,nick,tg,v}]}`, до 60 эфиров.

## Не проверено на практике
Коллаб через настоящий интернет (после правки v19 не прогонялся вообще: автопереподключение гостя, управление гостем, новый код оверлея), сцены в OBS, `watch_videos`, показ экрана партнёру, светлые темы. Скриншотами проверены только сцены «Перерыв» и «Конец стрима» (v19).

## Ограничения
Бот только читает чат. Работает, пока панель открыта. Громкостью Spotify/SoundCloud управлять нельзя. Очередь локальная. Серверные функции без ключей и бэкенда невозможны: говори прямо.

1) Сервер (Vercel functions + KV/Supabase) для общего состояния и бота с ответами. 2) Раскладки сторис, просмотр архива по месяцам. 3) Анимированный фон оверлея.
