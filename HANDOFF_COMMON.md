# ОБЩИЙ промпт: семейство проектов KOHbツ.FM / M1Z.FM / HMSTR.FM

Вставь этот файл + личный промпт нужного проекта (`HANDOFF_PROJECT_KOHb.md`, `HANDOFF_PROJECT_M1Z.md` или `HANDOFF_PROJECT_HMSTR.md`). Приложи файлы проекта: `index.html`, `overlay.html`, `request.html`, `sfx.js`, `og.png`, `api/yt.js`, `api/meta.js`, `api/feedback.js` (и `peerjs.min.js`, см. v27).

Актуально для **v28**.

---

Ты помогаешь развивать три одинаковых по коду сайта для радио-стримов на Twitch. Отвечай по-русски, коротко и по делу. Зрители присылают в чат (или на сайт заказов) ссылку (YouTube, Spotify и др.) или название трека, ведущий слушает, ставит оценку 1–10 и иногда добавляет трек в плейлист. Пишем «ведущий / ведущего» (у HMSTR «ведущая»).

## Главное правило
Три проекта держим **идентичными по коду**. Эталон: KOHbツ. Любую правку делаем там и переносим на M1Z и HMSTR (удобно писать Python-патч с `str.replace` и проверкой, что строка найдена ровно один раз, и применять его ко всем трём проектам). Отличаются только: название, ключи `<slug>_*`, комната `<slug>fm-`, канал по умолчанию, домен, баннер `og.png` (и род у HMSTR). В коде это одна строка в `index.html` (`const MAINO="<домен>",DEFCH="<канал>"`) и одна в `request.html` (`var MAINO="<домен>"`). Данные проекта лежат в его личном промпте.

## Файлы и хостинг
Чистый HTML/CSS/JS, без сборки. GitHub → Vercel. В корне: `index.html` (панель), `overlay.html` (оверлей для OBS), `request.html` (сайт заказов для зрителей), `sfx.js` (звуки, ключ из `window.SFX_KEY`), `og.png` (1200×630, версия `?v=N` в og-тегах). В папке `api/` три Vercel-функции: `yt.js` (поиск видео по названию, без ключей), `meta.js` (название и исполнитель по ссылке, только хосты из белого списка, без ключей) и `feedback.js` (идеи и ошибки зрителей в Telegram разработчика; нужны переменные окружения `TG_BOT_TOKEN`, `TG_CHAT_ID`, см. `SETUP_ОБРАТНАЯ_СВЯЗЬ.md`). Положи рядом с `index.html` файл `peerjs.min.js` (скачать один раз: `https://cdn.jsdelivr.net/npm/peerjs@1.5.4/dist/peerjs.min.js`): страницы грузят его первым, CDN остаётся запасным. Функции `api/` есть только на Vercel-домене; на зеркале страница сама обращается к основному домену (`MAINO`, CORS открыт).

## Что умеет панель
- **Очередь:** заявки вручную, из чата Twitch и с сайта заказов, drag-and-drop, дедупликация, лимит длины трека, приоритет донатов (`$`, слово-метка `cfg.donWord`). Кнопки VIP нет.
- **Плеер:** YouTube IFrame API, Spotify/SoundCloud через iframe, остальное виниловая заглушка и «↗ Открыть». Громкость только у YouTube.
- **Оценка** 1–10, теги настроения, «В плейлист», «Пропустить», «Следующий». Звуки: джингл, аплодисменты (9), горн (10), фейл (1). Быстрых комментариев нет (удалены в v20).
- **Чат Twitch:** анонимный IRC, только чтение. Команды `!заказ, !sr, !order`, лимиты, чёрный список, «На проверке», голосование `!1…!10`.
- **Эфир:** индикатор ON AIR (горит, пока есть текущий трек), кнопка **«В эфире»** со временем эфира (v26–v27, см. ниже), слепой режим, ☕ перерыв (K), ⏳ «скоро начнём» (L), 🏁 конец стрима (E), компактный и «Лёгкий» режимы, статистика.
- **Итоги:** хит-парад, архив 60 эфиров, лучшее за 30 дней, сторис-PNG 1080×1920, экспорт плейлиста.
- **30 тем** (id в `data-theme`): kohb/m1z/hmstr, neon, space, lagoon, sakura, matrix, retro, volcano, platinum, stage, aurora, sunset, frost, toxic, gold, noir, storm, obsidian, ruby, turq, copper, indigo, pine, contrast, tropics, rosegold, ultraviolet, empire, oled, olive. У каждой анимированный фон; типы фона: stars, pulse, waves, embers, blobs, fall, beams, grid, split.
- **Данные** в `localStorage` (`<slug>_fm_v1`, `_cfg`, `_theme`, `_vol`, `_arch`, `_brk`, `_photo`, `_coj`). Экспорт/импорт JSON `{S,cfg,arch}`. В экспорт и импорт **не входят** `ytKey`, `room`, `coKey`, `coOpen`, `pubCode`.

## Оверлей (`overlay.html`)
Данные от панели по WebRTC (PeerJS, `?room=КОД`, пир `<slug>fm-<room>`), запасной путь через `localStorage`. Параметры: `bg=green`, `q=0`, `logo=0`, `scene=0`, `lite=1`, `sw=`, `chat=0|own`, `chaturl=`, `chan=`. Сцены «Перерыв», «Скоро начнём», «Конец стрима» (анимированный фон, винил без смайлика, кольцо-таймер, пьедестал топ-3). В очереди оверлея вместо ссылки показывается «ссылка от @ник», пока нет названия.
`cfg.room` и `cfg.coKey` уникальны для каждого браузера и никогда не переносятся через экспорт. Если код оверлея совпал: Настройки → OBS-оверлей → «🔄 Новый код оверлея».

## 🤝 Коллаб (БЕТА)
Без сервера, WebRTC (PeerJS), работает между любыми проектами. Хозяин открывает комнату (`cfg.coOpen`), отдаёт код `<peer-id>~<coKey>`, один гость. Синхронизация: очередь, текущий трек, позиция/пауза, оценки обоих, заявки и голоса чата гостя, экран партнёра (`getDisplayMedia`). Права гостя: `coPp, coNx, coQu, coAd, coMod`. Гость переживает F5 (код в `<slug>_coj`, до 8 повторов раз в 4 с). Реакции 🔥👏😂😮❤️💀🎧, мини-чат, пинг и таймер «вместе», 🎯 при совпадении оценок, ссылка-приглашение `?co=КОД`, сердцебиение ping/pong. Плашка `#cobar`, плашка «🤝 Коллаб с ником» в оверлее. Гость при выходе сохраняет свои оценённые треки в историю и архив.

## Горячие клавиши (не ломать)
N следующий · Пробел пауза · 1–9, 0 оценка (0 = 10) · P плейлист · S пропуск · O открыть · ↑/↓ громкость · M звук · B слепой · T тема · D светлая/тёмная · K перерыв · L «скоро начнём» · V показ вкладки · E конец стрима · C чат в оверлее · Ctrl+Z вернуть предыдущий трек.

## Формат данных
`S = {queue:[], pending:[], current:null, history:[], evId}`. Трек: `id,text,nick,comment,rating,note,pl,title,author,name,skipped,src,tags,votes,vn,vavg,t0,thumb,cover,noemb,don,co` и служебные `mf` (название не нашлось после 3 попыток), `_mn` (когда повторить). Архив: `{id,d,t:[{n,r,nick,tg,v}]}`, до 60 эфиров.
**Названия:** `plRaw(x)` отдаёт как раньше (для плейлиста, экспорта, поиска обложки, переименования), `plName(x)` для экрана: если названия нет, вместо ссылки «🎵 YouTube» / «🎵 Spotify» и т. п. `plQ(x)` для очереди и заявок. Сама ссылка остаётся в `x.text`.

Раньше не проверялись: коллаб через настоящий интернет, сцены в OBS, показ экрана партнёру, светлые темы.

## Ограничения
Бот только читает чат. Всё работает, пока панель стримера открыта. Громкостью Spotify/SoundCloud управлять нельзя. Очередь локальная. Сигнальный сервер PeerJS (облачный) и TURN внешние: если они недоступны зрителю, зеркало не поможет. Собственный вход зрителя через Twitch (написать в чат из своего поля ввода) потребует регистрации приложения Twitch (Client ID). Серверные функции с ключами и бэкендом невозможны: говори прямо.

## План
0) Кнопка (i) с инфо и текстом песни отменена по просьбе автора.
1) Сервер (Vercel functions + KV/Supabase) для общего состояния и бота с ответами. 2) Раскладки сторис, просмотр архива по месяцам. 3) Собственная авторизация Twitch для чата на сайте заказов. 4) Автоопределение «в эфире» по статусу Twitch.

## Как со мной работать
Сначала коротко решение, потом готовый код целыми файлами. Не ломай горячие клавиши и формат данных без предупреждения. Визуал проверяй скриншотом в headless-браузере (оверлей и страницы открывать по http, не file://, иначе `localStorage` недоступен). Правки в `index.html`, `overlay.html`, `request.html` синхронно во все три проекта. Перед выдачей проверь, что в файлах проекта нет названий других проектов (кроме id тем).
