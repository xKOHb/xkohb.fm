# Промт для переноса проекта KOHbツ.FM в новый чат

Скопируй всё ниже и вставь в новый чат. Приложи `index.html`, `overlay.html`, `sfx.js`, `og.png`.

---

Ты помогаешь мне развивать сайт **KOHbツ.FM**. Отвечай по-русски, коротко и по делу.

## Контекст
Новый стример **KOHbツ** проводит радио-стримы на **Twitch**: зрители присылают в чат ссылку (YouTube, Spotify и др.) или название трека, он слушает, ставит оценку и иногда добавляет трек в плейлист. Сайт нужен, чтобы ему было удобно это делать. Везде пишем «ведущий / ведущего» (мужской род), не «ведущая».

Проект — переименованная копия M1Z.FM (которая сама была копией HMSTR.FM). Прежние названия проекта (M1Z, HMSTR и бывшее `bldthrll`) нигде не должны встречаться, кроме адреса Vercel и имени репозитория ниже.

## Файлы и хостинг
- Репозиторий GitHub `xKOHb/bldthrll.fm` → Vercel, сайт https://xkohbfm.vercel.app/ (новый адрес). Чистый HTML/CSS/JS, без сборки и сервера.
- Файлы в корне репозитория: `index.html` (панель), `overlay.html` (оверлей для OBS), `sfx.js` (звуки), `og.png` (баннер превью 1200×630).
- Ссылки на оверлей в панели ведут на `/overlay.html` (кнопки «Ссылка для Browser Source» и «Окно с зелёным фоном»).
- `sfx.js` берёт ключ настроек из `window.SFX_KEY="kohb_cfg"`.
- og-мета-теги в `index.html`: `og:url`/`og:image` указывают на `xkohbfm.vercel.app`, картинка подключена как `og.png?v=1` (при смене баннера увеличивать `v`).
- Баннер `og.png` в тёмной теме (чёрный, красный акцент, винил с наушниками, «Панель ведущего радио-стрима») генерировался скриптом на Python (Pillow, шрифт DejaVu Sans Bold); при необходимости можно пересоздать так же.

## Что умеет панель
- **Очередь:** заявка вручную или из чата Twitch → очередь (▶ играть сейчас, ✕), нумерация, перетаскивание (кнопка VIP убрана, приоритет даёт донат `$`), дедупликация по нормализованной ссылке, лимит длины трека (`cfg.maxmin`, проверка для YouTube).
- **Плеер:** YouTube IFrame API (название/автор через `getVideoData`, прогресс-бар с перемоткой), Spotify и SoundCloud через iframe, остальное — винил и «↗ Открыть». Громкость 50% по умолчанию (`kohb_vol`), только для YouTube. Для видео без встраивания: «↻ Обновить плеер», «↗ Открыть в новой вкладке», обложка по названию через iTunes Search (`c.cover`, флаг `c.noemb`).
- **Оценка:** 1–10 с подписью, эффекты на 9–10, 💀 и звук `SFX.fail` на 1, заметка, теги (Качает, Скучный, Весёлый, Не очень, 50/50), быстрые комментарии (Добавлен в плейлист, Прикольный, Мимо), «В плейлист» / «Пропустить» / «Следующий».
- **Чат Twitch (бот):** анонимный `wss://irc-ws.chat.twitch.tv` (`justinfan…`, только чтение). Команды по умолчанию `!заказ, !sr, !order`; лимит заявок на зрителя, пауза между заявками, чёрный список ников и слов, очередь «На проверке» (`S.pending`). Голосование чата `!1…!10` (`votes`, `vn`, `vavg`). Принимает ссылку вместо ника канала (`chanName`). Работает, пока панель открыта.
- **🤝 Коллаб (вдвоём):** Настройки → «Коллаб», кнопка 🤝 в шапке. Без сервера, по WebRTC (тот же PeerJS, что и оверлей), работает между любыми проектами (KOHbツ, M1Z, HMSTR). Хозяин открывает комнату (`cfg.coOpen`) и отдаёт гостю код `<peer-id>~<ключ>` (`cfg.coKey` создаётся автоматически, комната принимает только с верным ключом, один гость). Гость вставляет код и подключается: его `S` не трогается (`save()` не пишет в localStorage), на время коллаба он видит очередь и трек хозяина. Что синхронизируется: очередь и текущий трек, позиция и пауза плеера (у гостя играет свой YouTube-плеер, подстраивается при расхождении больше 2,5 с), оценка каждого (`c.co={n,r}`, у хозяина оценка гостя, у гостя оценка хозяина; в панели «🤝 ник: 8/10 · вместе 9.0», в оверлее чип «🤝 ник 8»), заявки из чата гостя (`!заказ` уходит в общую очередь хозяина, с проверкой дублей и «На проверке»), ручные заявки гостя, голоса чата гостя `!1…!10` (суммируются с голосами хозяина). Команды гостя (`next`, `skip`, `pp`, `go`, `del`, `don`) выполняются, если у хозяина включено `cfg.coCtl`. Экран друг-другу без задержки Twitch: кнопка «📺 Показать другу мой экран» (тот же `getDisplayMedia`, звонок партнёру `peer.call`), у партнёра появляется плавающее окно `#covid` (звук выключен по умолчанию). При выходе гостя его оценённые треки, плейлист и заметки попадают в его историю и архив (`coSess`, `coFlush`).
- **Эфир:** ON AIR, слепое прослушивание (B), таймер трека, ☕ «Перерыв» (K) и ⏳ «Скоро начнём» (L): `brk={on,until,kind}`, дублируется в `kohb_brk`. Компактный режим, статистика эфира (средняя, график, гистограмма).
- **Итоги:** хит-парад вечера с фильтром по тегам, «кураторы вечера» (8+), «Лучшее за 30 дней / за всё время» из архива `kohb_arch`, PNG для сторис 1080×1920 (стили по темам, фото ведущего в `kohb_photo`), экспорт плейлиста (список, CSV, ссылки, поиск в Яндекс Музыке/Spotify, «▶ Плейлист на YouTube» через `watch_videos?video_ids=`, до 50).
- **Плейлист:** копирование «Исполнитель – Название» с очисткой «Official Video / Lyrics / HD…» (`cleanTitle`, `plName`), опция «ссылки».
- **Звуки** (`sfx.js`): джингл, аплодисменты на 9, эйрхорн на 10, фейл на 1. Играют в панели или в оверлее (`cfg.snd`), громкость `cfg.sndVol`.
- **Показ вкладки браузера в оверлее** (Настройки → «📺 Показать мою вкладку» или клавиша V): `getDisplayMedia` в панели → `peer.call` по WebRTC (PeerJS) → `<video id="scrv">` в окне клипа оверлея (`#cscr`), флаг `scr` в `pubState`. Пока показ включён, окно клипа расширяется до `?sw=` (по умолчанию 1100) и YouTube-клип на паузе; когда показ выключен или вкладка закрыта, возвращается обложка/клип. `cfg.scrAudio` — звук вкладки (отметить «Поделиться звуком вкладки» в Chrome). Нужен Chrome/Edge и режим `?room=` (не работает через localStorage-запасной путь). Не проверено в OBS Browser Source.
- **Данные:** `localStorage`-ключи: `kohb_fm_v1` (состояние `S`), `kohb_cfg`, `kohb_theme`, `kohb_vol`, `kohb_arch`, `kohb_brk`, `kohb_photo`. Экспорт/импорт JSON (`{S,cfg,arch}`, без `ytKey`), файл `kohb-backup.json`.

### Формат данных
`S = {queue:[], pending:[], current:null, history:[], evId}`. Поля трека: `id,text,nick,comment,rating,note,pl,title,author,name,skipped,src,tags,votes,vn,vavg,t0,thumb,cover,noemb`. Архив эфира: `{id,d,t:[{n,r,nick,tg,v}]}`, до 60 эфиров, автосохранение при каждом завершённом треке.

### Кнопки очистки (не путать)
- **🗑 Новый эфир** (Настройки → Данные): сохраняет оценённые треки в архив, потом чистит очередь/историю. Нормальное завершение вечера.
- **🧨 Очистить всё** (Настройки → Данные и окно «За 30 дней / За всё время»): с подтверждением стирает очередь, «На проверке», историю, текущий трек **и архив**, сбрасывает голоса и заставку. Настройки, тема и фото ведущего остаются (`clearAll()`).

## Оверлей (`overlay.html`)
Получает данные от панели по WebRTC (PeerJS, `?room=КОД`, `cfg.room`, пир `kohbfm-<room>`), запасной путь — `localStorage` (`kohb_fm_v1`, `kohb_theme`) через `storage` и опрос раз в секунду. Чат в оверлее по умолчанию ВКЛЮЧЁН: внешний `chat.eblo.id` (канал `xk0hb`, `?chan=` меняет канал), `?chat=0` — выключить, `?chat=own` — встроенный. `?lite=1` — лёгкий оверлей (без конфетти/дождя/вспышки и бесконечных анимаций), `?sw=` — ширина окна показа вкладки (по умолчанию 880). Параметры: `?bg=green`, `?q=0` (скрыть очередь), `?logo=0`, `?scene=0` (без сцен). Показывает: выезд карточки, вращающийся винил, эквалайзер, штамп оценки с кольцом, пульсацию и конфетти на 9–10, дождь 🩸 на 10, 💀 на 1, чат-оценку в нижней строке карточки, список «Далее в эфире», сцены «Перерыв»/«Скоро начнём» с таймером и «Конец стрима» (итоги вечера: хит-парад топ-5, число треков, средняя, сколько в плейлист). Берёт только цвета темы панели (анимированные фоны тем в оверлее не рисуются, фон прозрачный/зелёный).

pubState (панель → оверлей): `t,pos,play,theme,blind,dur,vote,brk{rem,kind},ev{cnt,avg},hist,snd,sndVol,current{…,t0},queue`.

**Сцены (v18):** «Перерыв», «Скоро начнём», «Конец стрима» полностью переделаны: анимированный фон в цвете темы (плавающие свечения, бегущая сетка, поднимающиеся частицы), вращающийся винил с эмодзи, кольцо-таймер с обратным отсчётом (`scTot`, `#sca`), чипы статистики, подсказка `!заказ …` с ротацией текстов, карточки «Дальше в эфире» (до 4), эквалайзер внизу. «Конец стрима»: пьедестал топ-3 с медалями, места 4–5 списком, чипы «Треков / Средняя / В плейлист». В «Лёгком режиме» (`html.lite`) анимации сцен отключаются. Панель передаёт в `pubState` поле `cmd` (первая команда заказа) и `current.co` (оценка партнёра по коллабу).

## Ограничения
- В OBS: панель как Custom Browser Dock + оверлей как Browser Source (не проверено на практике). Запасной вариант: `overlay.html?bg=green` в окне браузера + Window Capture + Chroma Key.
- Бот читает чат, но не отвечает (нужен OAuth-токен и сервер). Работает только при открытой панели.
- Громкостью Spotify/SoundCloud из страницы управлять нельзя.
- Очередь и архив локальные (один браузер). Заявки с сайта от зрителей возможны только с сервером.
- Яндекс Музыка не даёт сторонним сайтам добавлять треки без своей авторизации.

## Не проверено на практике
Сцены в OBS, `watch_videos`, светлые темы (фоны упрощены), поиск обложки через iTunes (CORS), кнопка «🧨 Очистить всё», работа оверлея на `/overlay.html` (ссылки в панели исправлены в п. 18). Коллаб через настоящий интернет (проверен только эмуляцией WebRTC на двух страницах), показ экрана партнёру, новые сцены в OBS.

## План (по приоритету)
1. Серверная часть (Vercel functions + KV/Upstash или Supabase): общее состояние для панели, оверлея и бота.

3. Альтернативные раскладки сторис («постер», «минимал»), просмотр архива по месяцам, удаление отдельного эфира.
4. Анимированный/тематический фон в оверлее (сейчас только цвета).
